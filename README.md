# SuperNova VET

Aplicativo mobile desenvolvido em React Native com Expo para monitoramento preventivo da saúde de pets.

O projeto foi desenvolvido para o Challenge FIAP - 1º Sprint.

---

# Objetivo do Projeto

O SuperNova VET tem como objetivo auxiliar tutores no acompanhamento preventivo da saúde de seus pets, permitindo o controle de:

- Vacinas
- Medicamentos
- Cadastro de pets
- Informações preventivas

---

# Funcionalidades

- Navegação entre telas com React Navigation
- Cadastro de pets
- Formulário utilizando useState
- Persistência de dados com AsyncStorage
- Interface mobile funcional
- Armazenamento local dos dados

---

# Tecnologias Utilizadas

- React Native
- Expo
- React Navigation
- AsyncStorage
